### Run [cspell](#term-cspell)

```shell
sudo npm install -g cspell
cspell "**/*.md"
```

### Add new words to [Dictionary words list](#term-dictionary-words-list)

1. Open projectRoot/cspell.json
2. Add the new word to "words" field

### Use code spell check in [VS Code extension](#term-vs-code-extension)

<https://marketplace.visualstudio.com/items?itemName=streetsidesoftware.code-spell-checker>

## Terms

1. <a id="term-cspell"></a>**cspell:** A configurable spell checker commonly used for codebases and markdown.
2. <a id="term-dictionary-words-list"></a>**Dictionary words list:** Project-specific words added to avoid false positives.
3. <a id="term-vs-code-extension"></a>**VS Code extension:** Plugin that adds editor features without changing compiler/runtime behavior.
