## Terms

1. <a id="term-compiler-principles"></a>**Compiler principles:** Core theory for parsing, semantic analysis, IR, optimization, and code generation.
2. <a id="term-computer-architecture"></a>**Computer architecture:** How CPUs execute instructions, manage registers, memory hierarchy, and pipelines.
3. <a id="term-operating-systems-principles"></a>**Operating systems principles:** Process/thread scheduling, virtual memory, system calls, and protection.
